# 第二版阶段验收记录

更新时间：2026-07-03

## 1. 当前阶段结论

第二版已完成六个可验收的小闭环：

```text
资料 chunks 前端闭环
成长问答页接入 POST /api/agent/ask
资料历史问答保存和读回
历史问答复盘草稿入口
复盘草稿确认加入正式闪卡并保存复习状态
基础登录注册和用户数据隔离
```

当前第二版能力已经从第一版的持久化 MVP，推进到可以基于资料片段进行 AI 问答、保存问答历史、从历史问答进入正式闪卡复习，并通过 OpenAI-compatible Provider 完成真实模型人工联调的阶段。

## 2. 已完成能力

### 2.1 资料 chunks 闭环

已完成：

```text
1. 资料 content 可以生成 material_chunks。
2. chunks 可以保存到 SQLite。
3. 前端可以按资料读回 chunks。
4. 前端可以按关键词搜索 chunks。
5. 资料总结区可以展示生成、读回和搜索结果。
```

对应接口：

```text
POST /api/materials/{material_id}/chunks
GET /api/materials/{material_id}/chunks
GET /api/materials/search?query=...&limit=...
```

### 2.2 成长问答 agent ask 闭环

已完成：

```text
1. 前端通过 agentApi.ask() 调用 POST /api/agent/ask。
2. 成长问答页提交问题后展示 answer。
3. 助手消息展示回答依据 basis。
4. 助手消息展示学习建议 suggestion。
5. references 展示资料标题、chunk 序号、score 和片段内容。
6. 展示 confidence、mode 和是否基于资料。
7. isFromMaterial=false 或 confidence=low 时显示资料不足状态。
8. 资料总结区“问 AI”按钮可以预填资料问题并切到成长问答页。
9. 资料总结区可以直接围绕当前资料提问，并传入 materialId。
```

对应接口：

```text
POST /api/agent/ask
```

当前响应字段：

```text
answer
basis
suggestion
references
isFromMaterial
confidence
mode
```

### 2.3 资料历史问答闭环

已完成：

```text
1. 后端保存 material_qa_records。
2. 前端初始化时按资料读取 GET /api/materials/{material_id}/qa。
3. 资料总结区展示历史问答列表。
4. 提问成功后重新读取该资料的历史问答。
5. 历史问答展示 question、answer、basis、suggestion、sourceTitle、confidence 和资料不足状态。
6. 刷新页面后历史问答仍可读回。
```

对应接口：

```text
GET /api/materials/{material_id}/qa
POST /api/agent/ask
```

### 2.4 历史问答复盘入口

已完成：

```text
1. 每条资料问答记录提供“转闪卡草稿”和“记复习点”入口。
2. 记忆页新增“复盘草稿”区域。
3. 同一条 QA 的同类型草稿不会重复生成。
4. 支持删除复盘草稿。
5. 删除资料时清理对应本地复盘草稿，避免孤儿数据。
6. 用户确认后可以把复盘草稿加入正式闪卡。
7. 闪卡 known / review 打分状态会写回后端。
```

当前边界：

```text
复盘草稿先保存在前端 localStorage，不自动写入。
用户点击“加入闪卡”后，会通过后端接口写入 flashcards 表。
第二版不自动写入 quiz_questions，也不自动生成任务。
第二版暂不做完整间隔重复算法，只保留 new / known / review 状态。
```
