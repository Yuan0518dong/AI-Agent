# 第七版 Batch 4 资料不足修复记录

## 初始失败

首次固定集运行中，资料不足 Precision=`1.0`、Recall=`0.25`、F1=`0.4`，未达到 `0.80` 门槛。失败样例为 `qa18` 至 `qa23`：例如“TCP 三次握手如何避免半连接？”曾因“避免”等两字问句片段错误命中 `doc_07_guard`，并以 keyword score `1` 返回资料引用。

该结果为实际离线运行记录，未作为通过结果使用。根因是查询侧中文二字 n-gram 会将通用问句模板与无关资料的二字片段相交。

## 修复与复跑

`material_store.search_chunks` 现在仅在查询侧提取三至四字中文 n-gram，并过滤“如何”“什么”“时间”等问句停用词；资料侧关键词和 API/RRF 契约保持不变。复跑固定 32 条问答后：

| 指标 | 初始 | 修复后 |
|---|---:|---:|
| 引用准确率 | 0.25 | 0.75 |
| Groundedness | 0.25 | 0.75 |
| 资料不足 Precision | 1.0 | 1.0 |
| 资料不足 Recall | 0.25 | 0.75 |
| 资料不足 F1 | 0.4 | 0.8571 |

当前完整逐条结果见 `第七版Batch4问答评测报告.json`。`qa18` 至 `qa23` 作为回归样例仍保留在固定数据集中；本次修复后其中 6 条不再被无关资料支撑。
