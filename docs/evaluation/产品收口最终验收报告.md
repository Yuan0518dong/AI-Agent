## 学习闭环验收

自动化黄金流程覆盖：

```text
目标 -> 资料 -> 显式生成来源片段 -> 引用问答 -> 答错/薄弱点
-> create_review_draft -> 用户确认 -> 正式闪卡 -> FSRS good -> Today 变化
```

它断言确认前不写入正式闪卡；接受后新增一张到期卡；`good` 评级后卡片从 Today 到期项移除。首轮暴露的“接受后资料缓存未刷新”P1 已在独立提交 `a786546` 修复。详情见 [CLOSE-02 黄金流程报告](learning-loop-ux/close02-golden-flow-validation-report.md) 与 [CLOSE-01 一致性门禁](learning-loop-ux/close01-consistency-gate-validation-report.md)。

### 历史真实 Provider 固定集（A0 原始证据）

受授权的 DeepSeek 运行使用 20 个场景各 3 次：`60 Run`、`107` 次 Provider 请求、prompt/completion Token `237971/33611`、估算成本 `$0.042727`。工具选择为 `0.6333`，确认完整性为 `0.5556`，恢复成功率为 `1.0`，22 个 Run 未满足断言，安全回退为 84 次。

这组结果不是稳定模型能力结论。Guard `1.0` 来自真实响应后的受控非法 JSON 注入，只验证拦截链路，不衡量模型自然输出非法决策的概率。原始失败与指标保留在 [Batch 4 真实模型报告](第七版Batch4Agent真实模型评测报告.md)、[A0/A2/A3 对比](agent-reliability-a3/A0-A2-A3真实评测对比.md) 和 [legacy/corrected 离线报告](agent-reliability-rel/legacy-corrected-offline-report.md)。

在另一套 fixed corrected fixture 中，受授权运行完成 `60 Run`，其中 `57/126` 次为 Provider 请求，prompt/completion Token `94286/5553`，估算成本 `$0.014755/$0.27`，p50/p95 为 `2094/4454 ms`。系统工具选择、确认完整性、恢复成功和 Guard 注入召回均为 `1.0`，无失败 Run。
