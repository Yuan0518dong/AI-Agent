# 资料模块前后端接口对照

更新时间：2026-07-03

本文记录资料模块 MVP-1 / MVP-2 前端操作与后端 API 的对应关系。当前资料、摘要、闪卡、测试题、学习片段和成长问答入口的核心数据源已从前端本地生成切到后端接口；`localStorage` 仅作为页面状态快照和离线兜底。

## 1. 页面初始化

前端入口：

```text
app/app.js -> init() -> loadMaterialDataFromApi()
```

接口调用：

```text
GET /api/materials
GET /api/materials/{material_id}/summary
GET /api/materials/{material_id}/flashcards
GET /api/materials/{material_id}/quiz
GET /api/materials/{material_id}/chunks
```

前端处理：

```text
state.materials  <- materials + summary
state.flashcards <- all flashcards
state.quizzes    <- all quiz questions
state.materialChunks <- chunks grouped by materialId
```

展示位置：

```text
资料库：#material-list
资料总结：#summary-list
闪卡复习：#flashcard
测试题：#quiz-list
学习片段：#summary-list 内的 chunks 展示区
```

## 2. 新增资料并整理

前端入口：

```text
app/app.js -> #material-form submit
```

接口调用顺序：

```text
POST /api/materials
POST /api/materials/{material_id}/summarize
POST /api/materials/{material_id}/flashcards
POST /api/materials/{material_id}/quiz
GET  /api/materials + 派生数据读回
```

请求字段：

```json
{
  "goalId": "",
  "title": "第一章 细胞结构",
  "type": "text",
  "content": "资料正文或 PDF 摘录",
  "url": ""
}
```

网页链接资料：

```json
{
  "goalId": "",
  "title": "课程网页",
  "type": "link",
  "content": "",
  "url": "https://example.com"
}
```

响应字段：

```text
materials: id, goalId, title, type, content, url, createdAt, updatedAt
summary: materialId, overview, keyPoints, difficulties, studyOrder, actionItems, aiMode, createdAt, updatedAt
flashcards: id, materialId, front, back, status, createdAt, updatedAt
quiz: id, materialId, question, type, options, answer, explanation, createdAt, updatedAt
chunks: id, materialId, chunkIndex, content, keywords, createdAt, updatedAt
```

## 3. 编辑资料

前端入口：

```text
app/modules/materials.js -> startMaterialEdit(id)
app/app.js -> #material-form submit
```

接口调用顺序：

```text
PUT  /api/materials/{material_id}
POST /api/materials/{material_id}/summarize
POST /api/materials/{material_id}/flashcards
POST /api/materials/{material_id}/quiz
GET  /api/materials + 派生数据读回
```

前端处理：

```text
点击“编辑”后回填同一个资料表单；保存时根据 editingMaterialId 选择 PUT。
保存后重新生成摘要、闪卡和测试题，避免派生内容继续使用旧资料。
```

## 4. 删除资料

前端入口：

```text
app/modules/materials.js -> deleteMaterial(id)
```

接口调用：

```text
DELETE /api/materials/{material_id}
GET    /api/materials + 派生数据读回
```

后端行为：

```text
SQLite 外键 ON DELETE CASCADE 删除对应 summary、flashcards、quiz_questions。
```

前端处理：

```text
重新读取资料模块数据；同时清理本地问答会话中的 relatedMaterialIds。
```

## 5. 生成和搜索学习片段

前端入口：

```text
app/modules/materials.js -> renderSummaries()
资料总结区 -> “生成片段”
资料总结区 -> 搜索学习片段
```

接口调用：

```text
POST /api/materials/{material_id}/chunks
GET  /api/materials/{material_id}/chunks
GET  /api/materials/search?query={query}&limit=5
```

前端处理：

```text
1. 页面初始化时按资料读取 chunks，并写入 state.materialChunks。
2. 点击“生成片段”后调用 POST /chunks，并用响应更新当前资料的 chunks。
3. 在资料总结区展示片段序号、关键词和片段内容。
4. 搜索学习片段时调用 /api/materials/search，并在资料总结区上方展示命中片段。
```

用途边界：

```text
当前 chunks 属于第二版 AI 问答前的上下文准备能力。
它是关键词检索和上下文展示，不是完整向量 RAG。
```

## 6. 成长问答 agent ask 前端链路

前端入口：

```text
app/app.js -> #chat-form submit
app/api.js -> agentApi.ask()
app/modules/chat.js -> renderChat()
app/modules/materials.js -> prefillQuestionFromMaterial()
```

接口调用：

```text
POST /api/agent/ask
```

请求字段：

```json
{
  "question": "How does RAG retrieval answer questions?",
  "goalId": "goal_xxx",
  "limit": 3
}
```

响应字段：

```text
answer
basis
suggestion
references
isFromMaterial
confidence
mode
```

前端处理：

```text
1. 用户在成长问答页提交问题。
2. 前端调用 agentApi.ask() 请求 /api/agent/ask。
3. 助手消息展示 answer。
4. 助手消息下方展示 basis、suggestion、confidence、mode 和是否基于资料。
5. references 折叠展示资料标题、chunk 序号、score 和片段内容。
6. isFromMaterial=false 或 confidence=low 时展示资料不足状态。
7. 资料总结区的“问 AI”按钮只预填问题并切到成长问答页，不自动提交。
```

当前边界：

```text
1. 当前正式提交入口在成长问答页；资料总结区提供预填问题入口。
2. 当前后端返回 mode=mock，尚未接入真实大模型。
3. GET /api/materials/{material_id}/qa 尚未实现，历史问答持久化列表暂不接入。
4. 问答 references 来自 chunks 检索结果，前端只负责展示来源和资料不足提示。
```

## 7. 当前已接入

```text
1. 页面初始化读取 GET /api/materials。
2. 新增资料先写入 SQLite，再生成摘要、闪卡和测试题。
3. 刷新页面后，资料、摘要、闪卡、测试题仍能从后端读回。
4. 编辑资料走 PUT /api/materials/{material_id}，保存后重新生成派生练习。
5. 删除资料后，资料库和派生练习不再显示该资料的数据。
6. 资料总结区已接入 chunks 生成、读回和关键词搜索展示。
7. 成长问答页已接入 POST /api/agent/ask，并展示 answer、basis、suggestion、references、confidence 和 mode。
8. 资料总结区已提供“问 AI”入口，可预填资料相关问题并切到成长问答页。
```

## 8. 暂未接入

```text
1. 资料摘要、闪卡、测试题仍由后端 mock/rule-based AI service 生成，不是真实大模型。
2. 资料编辑时暂未单独编辑 goalId 归属，当前仍沿用页面选中目标或空目标。
3. chunks 搜索仍是关键词检索，不是 embedding / 向量数据库。
4. 资料详情页内的独立问答历史列表尚未接入。
5. GET /api/materials/{material_id}/qa 尚未实现，历史问答持久化列表暂未接入。
6. 真实大模型 / LangChain 问答链尚未接入。
```
