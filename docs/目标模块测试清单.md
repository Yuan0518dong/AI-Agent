# 目标模块测试清单

本文档用于目标管理、行动计划、今日任务、打卡和进度统计模块的手动回归测试。

## 测试前准备

1. 启动后端：

```bash
python -m uvicorn backend.app.main:app --reload
```

2. 启动前端：

```bash
cd app
python -m http.server 5500
```

3. 打开页面：

```text
http://127.0.0.1:5500
```

4. 打开接口文档：

```text
http://127.0.0.1:8000/docs
```

## 自动化接口测试

运行命令：

```bash
pytest backend/tests
```

当前自动化测试覆盖：

| 模块 | 场景 | 预期结果 |
| --- | --- | --- |
| 健康检查 | 请求 `/api/health` | 返回 `status=ok` |
| 目标管理 | 创建目标 | 返回目标详情和 `id` |
| 目标管理 | 查询目标列表 | 能看到刚创建的目标 |
| 目标管理 | 查询目标详情 | 能按 `goal_id` 获取目标 |
| 目标管理 | 只修改 `daily_minutes` | 其他字段不被覆盖 |
| 行动计划 | 生成 3 天计划 | 返回 3 个任务 |
| 今日任务 | 查询今日任务 | 能看到当天任务 |
| 打卡 | 任务打卡 | `done=true`，并生成完成时间 |
| 打卡 | 取消打卡 | `done=false`，完成时间清空 |
| 进度统计 | 查询单目标进度 | 完成数和完成率正确变化 |
| 删除目标 | 删除目标后查询详情 | 返回 404 |
| 异常处理 | 查询不存在的目标和任务 | 返回 404 |
| 参数校验 | 创建非法目标 | 返回 422 |

## 当前边界

1. 当前 `dev` 分支的后端存储仍是内存版，服务重启后数据会丢失。
2. 如果后续重新接入 SQLite，本测试清单仍适用，但自动化测试需要增加测试数据库隔离。
3. 资料、AI 整理、闪卡和问答模块不属于本文档范围。
