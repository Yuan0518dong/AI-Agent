# 通用成长学习助手 App 第三版项目计划书

更新时间：2026-07-06

## 1. 第三版最新定位

第三版定位调整为：

```text
可控学习智能体 MVP 继续推进版
```

本次调整原因：

```text
1. 第二版已经可以演示，不需要把第三版写成“修修补补式收尾”。
2. 实习还有约三天，仍然可以继续向“智能体交付”推进一层。
3. 当前项目不适合突然扩张成完整 Agent 平台，但适合把已有资料学习链路做得更智能、更可验收。
4. 当前协作方式调整为“各自推进自己的负责方向”，不再把第三版写成强绑定双人任务。
```

第三版目标不是重新做一套系统，而是在第二版稳定闭环上继续推进：

```text
资料学习链路
-> 资料学习智能体链路
```

第三版对外表达：

```text
第一版完成了学习助手的 SQLite 持久化闭环。
第二版完成了基于资料 chunks 的 AI 问答、历史问答和闪卡复习闭环。
第三版继续推进为可控学习智能体 MVP：系统不只是回答问题，还能判断资料是否足够，输出下一步学习动作，生成待确认复习草稿，并通过样例验证不编造。
```

## 3. 第三版智能体定义

本项目第三版中的“智能体”不是完整自动 Agent 循环，而是一个可控学习智能体：

```text
上下文感知：读取目标、资料、chunks、问答历史和当前资料上下文。
有限判断：判断能否基于资料回答、是否资料不足、下一步该复习还是补资料。
结构化输出：返回 answer、basis、references、confidence、nextAction、requiresConfirmation、reviewDrafts。
用户确认：AI 只能生成草稿，正式闪卡、复习内容或任务必须由用户确认写入。
可验收：通过固定样例证明它能回答、能建议、能拒绝资料外问题。
```

第三版不追求：

```text
自动联网
自动改任务
自动写正式复习内容
完整 LangChain Agent
向量数据库
PDF / Office 文档解析
复杂记忆算法
正式部署
```

## 4. 已完成闭环

### 4.1 最小智能体字段

已完成：

```text
POST /api/agent/ask 返回：
- nextAction
- requiresConfirmation
- insufficiencyReason
- reviewDrafts
```

字段意义：

```text
nextAction：Agent 建议用户下一步做什么。
requiresConfirmation：是否需要用户确认后才能写入正式学习内容。
insufficiencyReason：资料不足时说明缺少什么依据。
reviewDrafts：Agent 生成的待确认复盘草稿。
```

### 4.2 资料学习智能体前端闭环

已完成：

```text
成长问答新增“智能体验收”入口：
- 资料内回答
- 复习建议
- 资料不足

点击样例后：
1. 自动绑定当前资料。
2. 自动填入验收问题。
3. 用户发送给 Agent。
4. Agent 回答同步到资料问答历史。
5. 当前问答历史高亮。
6. 用户点击“采纳 Agent 草稿”。
7. 自动进入复盘草稿区。
8. 当前复盘草稿高亮。
9. 用户点击“加入闪卡”。
10. 草稿进入正式闪卡复习。
```

## 5. 接下来三天推进目标

第三版现在不收尾，但也不扩张。接下来只推进能增强“智能体感”和“交付证据”的内容。

### 5.1 P0：真实模型浏览器验收

目标：

```text
证明第三版资料学习智能体在真实使用场景下能稳定走通。
```

验收样例：

```text
1. 资料内回答：
   问题能基于当前资料回答，并给出依据。

2. 复习建议：
   问题能触发 nextAction、学习建议和待确认草稿。

3. 资料不足：
   问题超出资料时，Agent 明确说明资料不足，不生成可直接采纳的复习草稿。
```

证据：

```text
Agent 回答截图
资料问答历史高亮截图
复盘草稿高亮截图
正式闪卡截图
真实模型 mode 截图或接口返回记录
```

### 5.2 P1：问答质量优化

目标：

```text
让问答更符合真实用户学习体验，而不是只返回“核心含义是什么”的泛化回答。
```

可做内容：

```text
1. 优化 Prompt，让模型更明确地区分：
   - 资料内回答
   - 复习建议
   - 资料不足

2. 优化结构化输出归一化：
   - nextAction 枚举兜底
   - reviewDrafts 类型兜底
   - requiresConfirmation 与草稿联动

3. 增加少量 AI 评估样例：
   - 资料内问题
   - 资料边界问题
   - 资料外问题
```

边界：

```text
不做完整评测平台。
不引入 LangChain。
不接向量数据库。
不让 AI 自动写正式任务或闪卡。
```

### 5.3 P2：智能体体验细节

目标：

```text
让用户更容易理解 Agent 的判断和下一步动作。
```

可做内容：

```text
1. 让 Agent 建议更醒目。
2. 让资料不足原因更容易被看见。
3. 避免重复采纳草稿造成困惑。
4. 让从问答历史到复盘草稿的跳转更稳定。
```

边界：

```text
只优化资料学习链路。
不改陈负责的目标、今日、进度核心逻辑。
不做大面积视觉重构。
```

## 8. 验收标准

### 8.1 功能验收

```text
1. 成长问答能基于当前资料发问。
2. Agent 回答包含依据、建议、confidence、nextAction。
3. Agent 能说明资料不足原因。
4. Agent 生成的草稿必须 requiresConfirmation=true。
5. 用户确认后才能进入复盘草稿和正式闪卡。
6. 正式闪卡可以继续 known / review。
```
