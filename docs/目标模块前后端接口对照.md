# 目标模块前后端接口对照

更新时间：2026-07-01

## 1. 模块范围

本文档记录陈负责的目标模块前后端对应关系。

目标模块主线：

```text
目标管理 -> 行动计划 -> 今日任务 -> 打卡 -> 进度统计
```

当前技术链路：

```text
app/index.html + app/app.js
  -> app/api.js
  -> FastAPI backend/app/routers
  -> SQLite backend/data/ai_agent.db
```

## 2. 前端文件分工

| 文件 | 作用 |
|---|---|
| app/index.html | 目标表单、目标列表、目标详情、今日任务、进度展示结构 |
| app/app.js | 页面状态、事件监听、渲染逻辑、字段转换 |
| app/api.js | 统一封装目标模块 API 请求 |
| app/styles.css | 目标详情、任务列表、提示条、按钮状态样式 |

## 3. 后端文件分工

| 文件 | 作用 |
|---|---|
| backend/app/main.py | 注册路由，配置 CORS |
| backend/app/routers/goals.py | 目标 CRUD、计划生成、目标任务列表 |
| backend/app/routers/tasks.py | 今日任务、任务打卡 |
| backend/app/routers/progress.py | 整体进度、单目标进度 |
| backend/app/services/store.py | SQLite 读写 |
| backend/app/services/plan_service.py | 规则生成行动计划 |
| backend/app/services/progress_service.py | 统计任务完成情况 |

## 4. 前后端字段转换

后端使用 Python / SQLite 常见的 `snake_case`，前端使用 JavaScript 常见的 `camelCase`。

| 后端字段 | 前端字段 | 说明 |
|---|---|---|
| daily_minutes | dailyMinutes | 每天学习分钟数 |
| goal_id | goalId | 目标 ID |
| completed_at | completedAt | 任务完成时间 |
| created_at | createdAt | 创建时间 |
| updated_at | updatedAt | 更新时间 |
| total_tasks | totalTasks | 总任务数 |
| completed_tasks | completedTasks | 已完成任务数 |
| completion_rate | completionRate | 完成率 |
| today_total | todayTotal | 今日任务数 |
| today_completed | todayCompleted | 今日已完成数 |

转换位置：

```text
app/app.js
goalFromApi()
taskFromApi()
progressFromApi()
```

## 5. 接口对照

### 5.1 获取目标列表

| 项目 | 内容 |
|---|---|
| 前端入口 | 页面初始化、目标列表刷新 |
| 前端函数 | loadGoalDataFromApi() |
| API 封装 | goalApi.listGoals() |
| 后端接口 | GET /api/goals |
| 后端路由 | backend/app/routers/goals.py:list_goals |
| 返回用途 | 渲染目标列表、学习状态、整体指标 |

### 5.2 创建目标

| 项目 | 内容 |
|---|---|
| 前端入口 | 目标表单提交 |
| 前端函数 | goal-form submit listener |
| API 封装 | goalApi.createGoal(payload) |
| 后端接口 | POST /api/goals |
| 后端路由 | backend/app/routers/goals.py:create_goal |
| 请求体 | name、subject、level、deadline、daily_minutes、notes |
| 成功后动作 | 自动生成计划、刷新目标/任务/进度、打开该目标上下文 |

请求示例：

```json
{
  "name": "准备英语四级",
  "subject": "英语",
  "level": "有基础",
  "deadline": "2026-07-30",
  "daily_minutes": 60,
  "notes": "重点突破听力和阅读"
}
```

### 5.3 编辑目标

| 项目 | 内容 |
|---|---|
| 前端入口 | 目标卡片“编辑”、目标详情“编辑” |
| 前端函数 | startGoalEdit()、fillGoalForm() |
| API 封装 | goalApi.updateGoal(goalId, payload) |
| 后端接口 | PUT /api/goals/{goal_id} |
| 后端路由 | backend/app/routers/goals.py:update_goal |
| 请求体 | 允许提交目标字段的部分或全部 |
| 成功后动作 | 重新加载目标列表和当前目标详情 |

注意：

```text
后端使用 exclude_unset 和 exclude_none 做局部更新，避免未提交字段覆盖原数据。
```

### 5.4 删除目标

| 项目 | 内容 |
|---|---|
| 前端入口 | 目标卡片删除按钮 |
| 前端函数 | deleteGoal(id) |
| API 封装 | goalApi.deleteGoal(goalId) |
| 后端接口 | DELETE /api/goals/{goal_id} |
| 后端路由 | backend/app/routers/goals.py:delete_goal |
| 成功后动作 | 清空当前详情/编辑状态，刷新列表 |

说明：

```text
SQLite tasks 表通过外键 ON DELETE CASCADE 关联 goals。
删除目标后，该目标下任务会随目标删除。
```

### 5.5 获取目标详情

| 项目 | 内容 |
|---|---|
| 前端入口 | 目标卡片“详情”、进度页“查看详情” |
| 前端函数 | selectGoal(goalId)、loadSelectedGoalFromApi(goalId) |
| API 封装 | goalApi.getGoal(goalId) |
| 后端接口 | GET /api/goals/{goal_id} |
| 后端路由 | backend/app/routers/goals.py:get_goal |
| 返回用途 | 渲染目标详情面板 |

### 5.6 生成行动计划

| 项目 | 内容 |
|---|---|
| 前端入口 | 生成计划、目标卡片“计划”、详情页“重新生成计划” |
| 前端函数 | generatePlanForGoalApi()、regenerateGoalPlan()、generatePlansForAllGoals() |
| API 封装 | goalApi.generatePlan(goalId, days) |
| 后端接口 | POST /api/goals/{goal_id}/plans |
| 后端路由 | backend/app/routers/goals.py:generate_plan |
| 请求体 | days、regenerate |
| 当前前端支持 | 3 天、7 天、14 天 |

请求示例：

```json
{
  "days": 7,
  "regenerate": true
}
```

### 5.8 获取指定日期任务

| 项目 | 内容 |
|---|---|
| 前端入口 | 今日任务日期选择器 |
| 前端函数 | loadGoalDataFromApi() |
| API 封装 | goalApi.listTodayTasks(date) |
| 后端接口 | GET /api/tasks/today?date=YYYY-MM-DD |
| 后端路由 | backend/app/routers/tasks.py:list_today_tasks |
| 返回用途 | 展示指定日期任务 |

说明：

```text

```

## 6. 前端交互状态

| 状态 | 变量 | 作用 |
|---|---|---|
| 当前编辑目标 | editingGoalId | 判断目标表单是创建还是编辑 |
| 当前查看目标 | selectedGoalId | 控制详情面板加载哪个目标 |
| 当前任务日期 | selectedTaskDate | 控制今日任务列表查询日期 |
| 目标详情数据 | state.selectedGoal | 当前目标详情 |
| 目标任务数据 | state.selectedGoalTasks | 当前目标全部任务 |
| 单目标进度 | state.selectedGoalProgress | 当前目标统计数据 |

## 7. 当前验收标准

目标模块通过验收需要满足：

```text
1. 前端可以创建目标。
2. 创建目标后自动生成行动计划。
3. 前端刷新后目标仍然存在。
4. 可以编辑目标，修改后后端和页面都更新。
5. 可以删除目标，关联任务和进度同步消失。
6. 可以查看目标详情。
7. 可以查看某个目标下的全部任务。
8. 可以选择 3 / 7 / 14 天生成计划。
9. 可以选择日期查看任务。
10. 今日任务和详情任务都可以打卡 / 取消打卡。
11. 整体进度和单目标进度会随打卡变化。
12. 重启后端后，数据仍然能从 SQLite 读取。
```

## 8. 已知边界

```text
1. 当前仍是单用户模式，没有用户隔离。
2. 计划生成仍是规则生成，不是真实 AI。
3. 资料、AI、闪卡、测试题、问答模块仍主要依赖 localStorage。
4. 前端仍是原生 HTML/CSS/JS，后续可根据需要再迁移到 Vue 或 React。
```
