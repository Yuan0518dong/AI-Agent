## 第一版产品闭环

第一版优先保住这条主线：

```text
目标 -> 资料 -> AI 整理 -> 计划 -> 打卡 -> 进度
```

完整形态可以扩展为：

```text
注册登录 -> 创建成长目标 -> 添加资料 -> AI 整理资料 -> 生成行动计划 -> 完成今日打卡 -> 查看进度
```

阶段口径：

```text
MVP-0：静态 / 本地演示闭环，允许 localStorage 和 mock AI，目标是讲清楚产品流程。
MVP-1：工程化最小版，加入前后端边界、数据库持久化、最小真实 AI 接口。
MVP-2：补注册登录、用户隔离、PDF 上传、部署和更完整测试。
```

如果时间或实现难度需要收敛，优先保住 MVP-0 到 MVP-1 的主线。注册登录、PDF 上传、正式部署默认放到 MVP-2，除非导师明确要求第一版必须具备。
