# 第三版资料学习智能体验收样例

## 验收目标

验证第三版资料学习链路已经从普通问答推进到可控学习智能体 MVP：

- 能基于当前资料回答问题；
- 能给出下一步学习动作；
- 能在适合时生成待确认复盘草稿；
- 能在资料不足时拒绝把资料外知识伪装成资料结论；
- 能由用户确认后进入复盘草稿，并再加入正式闪卡。

## 样例一：资料内回答

问题：

```text
请只根据《当前资料标题》回答：这份资料里最重要的概念、人物、意象或知识点是什么？请说明依据。
```

预期：

- `isFromMaterial=true`
- 回答引用当前资料内容
- 出现依据或来源片段
- 允许产生待确认草稿

证据：

- 成长问答截图
- 资料问答历史截图

## 样例二：复习建议

问题：

```text
请基于《当前资料标题》解释这份资料的核心内容，并给我下一步复习建议。
```

预期：

- 出现 `nextAction`
- 出现 Agent 建议
- 出现可采纳的复盘草稿
- 点击“采纳 Agent 草稿”后进入复盘草稿区

证据：

- Agent 建议截图
- 复盘草稿区“当前草稿”截图

## 样例三：资料不足判断

问题：

```text
请只根据《当前资料标题》回答：Transformer 的多头注意力公式是什么？如果资料没有依据，请说明资料不足。
```

预期：

- `isFromMaterial=false`
- `nextAction=ask_for_more_material`
- 出现资料不足原因
- 不生成可直接加入正式复习的草稿

证据：

- 资料不足提示截图
- 问答历史中资料不足原因截图

## 当前前端入口

成长问答面板新增“智能体验收”入口：

- 资料内回答
- 复习建议
- 资料不足

点击后会自动基于当前绑定资料填入对应问题，方便后续真实模型人工验收。

## 闭环路径

1. 在成长问答点击一个智能体验收样例。
2. 发送问题，等待 Agent 回答。
3. Agent 回答会同步进入右侧资料问答历史，并高亮当前记录。
4. 如果 Agent 生成了待确认草稿，点击“采纳 Agent 草稿”。
5. 系统进入复盘草稿区并高亮当前草稿。
6. 点击“加入闪卡”，草稿进入正式闪卡复习。
