## 2. 三类 AI 问答验收样例

### 2.1 资料中有明确答案

测试资料：

```text
RAG uses retrieval to find relevant chunks before generating an answer.
Retrieval grounds the answer in material evidence and reduces unsupported responses.
```

测试问题：

```text
RAG 如何把回答建立在资料证据上？
```

期望结果：

```text
1. 回答应提到 retrieval / chunks / material evidence。
2. references 至少返回 1 条相关资料片段。
3. isFromMaterial 为 true。
4. confidence 不应为 low。
5. 前端展示 answer、basis、suggestion 和来源片段。
```

### 2.2 资料中只有部分答案

测试资料：

```text
Spaced repetition helps learners review difficult knowledge over time.
Flashcards can be used to check whether a learner can recall key ideas.
```

测试问题：

```text
这份资料是否说明了如何用 LangChain 实现间隔重复？
```

期望结果：

```text
1. 回答可以说明资料包含间隔重复和闪卡，但没有 LangChain 实现细节。
2. basis 应指向资料中已有内容，而不是补造实现方案。
3. suggestion 可以建议补充 LangChain 相关资料。
4. 不能把资料没有写的技术实现当成资料结论。
```

### 2.3 资料中没有答案

测试资料：

```text
This note describes how to create flashcards from learning materials.
It does not discuss deployment, authentication, or payment systems.
```

测试问题：

```text
这个系统应该如何设计登录和支付？
```

期望结果：

```text
1. 必须说明当前资料不足以直接回答。
2. 如果给通用建议，需要标注不是来自当前资料。
3. isFromMaterial 应为 false 或 confidence 应为 low。
4. 前端应显示资料不足状态。
5. references 可以为空或只展示低相关片段，但不能包装成强依据。
```

## 3. 第二版演示脚本

演示主线：

```text
第一版：证明目标、资料、计划、记忆、进度的持久化闭环。
第二版：证明资料可以被切分、检索、问答、保存历史，并进入复习。
```

演示步骤：

```text
1. 启动后端和前端。
2. 创建或选择一个成长目标。
3. 添加一份与目标相关的学习资料。
4. 确认资料摘要、闪卡和测试题仍可生成。
5. 进入成长问答 / 资料总结区，点击生成 chunks。
6. 搜索资料片段，证明 chunks 可检索。
7. 围绕资料提问一个有明确答案的问题。
8. 展示 answer、basis、suggestion、references、confidence。
9. 刷新页面，回到资料总结区，展示历史问答仍存在。
10. 从某条历史问答点击“转闪卡草稿”或“记复习点”。
11. 进入记忆页，展示复盘草稿。
12. 回到今日任务、目标详情或进度页，证明第一版主流程未破坏。
```
