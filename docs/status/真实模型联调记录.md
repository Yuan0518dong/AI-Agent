## 4. 三类验收问题

### 4.1 资料中有明确答案

```text
测试资料：
RAG uses retrieval to find relevant chunks before generating an answer.
Retrieval grounds the answer in material evidence and reduces unsupported responses.

测试问题：
RAG 如何把回答建立在资料证据上？

结果：
是否通过：通过
问题记录：返回 mode=openai-compatible，isFromMaterial=true，confidence=high；回答能说明 RAG 通过检索相关片段并基于材料证据生成答案。
```

### 4.2 资料中只有部分答案

```text
测试资料：
Spaced repetition helps learners review difficult knowledge over time.
Flashcards can be used to check whether a learner can recall key ideas.

测试问题：
这份资料是否说明了如何用 LangChain 实现间隔重复？

结果：
是否通过：修复后通过
问题记录：首次真实模型会用常识补充 LangChain，并错误标记为 isFromMaterial=true。已在 Provider 增加问题技术词缺失防护：当问题中的英文技术词没有出现在资料片段中时，强制标记为资料不足。复测后返回 isFromMaterial=false，confidence=low。
```

### 4.3 资料中没有答案

```text
测试资料：
This note describes how to create flashcards from learning materials.
It does not discuss deployment, authentication, or payment systems.

测试问题：
这个系统应该如何设计登录和支付？

结果：
是否通过：通过
问题记录：返回 mode=openai-compatible，isFromMaterial=false，confidence=low；回答明确说明资料不足，无法回答登录和支付设计。
```

## 7. 浏览器真实模型主流程

联调方式：

```text
后端临时启动在 8001，并配置：
LLM_PROVIDER=openai-compatible
LLM_MODEL=glm-4-flash-250414
LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4

前端仍通过 5500 打开，Playwright 临时把 api.js 的 API_BASE_URL 改到 8001。
代码文件未写入 API Key，也未修改 app/api.js。
```

浏览器流程：

```text
1. 新增资料 Real LLM browser smoke。
2. 生成 chunks。
3. 围绕资料提问：RAG retrieval 如何让回答基于 evidence chunks？
4. GET /api/materials/{material_id}/qa 读回 QA 记录。
5. 从历史问答生成闪卡草稿。
6. 删除 smoke 资料清理测试数据。
```
