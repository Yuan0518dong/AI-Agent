# 个人贡献说明

## 项目身份

AI-Agent 是维护者在本次实习期间持续投入的唯一研发项目，也是使用个人可公开资源完成的作品集项目。它不是实习之外另起的副项目，也不是公司核心业务系统、内部生产系统或真实用户生产服务。

项目可以同时作为实习成果和个人公开作品展示，但必须保留协作开发与个人独立负责阶段的事实边界。

## 独立推进的核心能力

第四版至 v7.1.0 期间，维护者独立推进的新增能力包括：

- 多步 Agent Runtime、持久化 AgentStep、工具执行观察回灌、停止边界与取消互斥。
- Tool Registry、草稿态执行、确认写入、同一 Run 恢复与重复写入保护。
- Decision Guard、Hybrid Decision Provider、模型输出范围/JSON 校验和 rule-based 安全回退。
- 第七版的数据库会话、公开 Demo、PDF/Markdown/TXT 摄取、pgvector 检索、固定评测、Playwright 和 CI 门禁。
- v7.1.0 的 Agent 可靠性收口、FSRS 学习闭环、Today Actions、黄金流程验收、求职材料冻结与公开发布验证。

开发过程中使用 AI 辅助工具提高实现和审查效率；“独立负责”指维护者独立承担需求拆解、技术取舍、代码集成、问题定位、验证和交付责任，不表示所有代码均在无工具辅助下手写。
