# 90 秒演示脚本

对应录屏：[v7-batch4-90s-demo.webm](../videos/v7-batch4-90s-demo.webm)，本地文件时长 `00:01:31`。它使用隔离 SQLite 和 Mock Provider，作为 Batch 4 UI/流程证据，不替代真实模型验收。

| 时间 | 画面与操作 | 口播重点 |
|---|---|---|
| 0-10 秒 | 打开在线 Demo 与“一键试用” | 同源会话创建隔离 Demo 数据，不调用真实模型。 |
| 10-25 秒 | 创建目标，上传一页 PDF | 展示目标到资料的入口，以及 PDF 只保存提取文本和来源定位。 |
| 25-40 秒 | 在问答页提问，展开引用 | 回答显示资料、页码/定位、检索模式和分数；无证据时直接资料不足。 |
| 40-60 秒 | 打开智能任务，展开运行详情 | 展示持久化步骤、Decision Guard、工具 I/O 与待确认写入。 |
| 60-75 秒 | 接受一次确认并恢复，再演示拒绝或取消 | 高风险写入需确认；拒绝不落正式数据，取消后 Run 不再推进。 |
| 75-90 秒 | 切到 390px 视图，展示评测报告 | 移动端无横向溢出；区分录屏的 Mock 流程与已完成的 20 x 3 真实 Agent 报告，并如实说明工具选择和确认完整性未达稳定水平。 |

录制检查：使用 Demo 或隔离测试库；隐藏浏览器密码/扩展；不展示 Provider 配置、Cookie、连接串或用户数据；不得把 Mock、单次 smoke 或受限真实评测说成完整真实模型结论。
