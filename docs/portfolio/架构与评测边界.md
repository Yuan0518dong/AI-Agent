# 架构与评测边界

当前对外指标、门禁与冻结状态以 [产品收口最终验收报告](../evaluation/产品收口最终验收报告.md) 为唯一汇总来源；本页解释架构和证据边界，不重算或覆盖原始评测。

## 运行架构

```text
同源浏览器
  -> FastAPI 路由
  -> 会话、限流、Origin 校验
  -> 资料上传/解析 -> chunk + embedding -> keyword/dense/RRF
  -> 问答引用或 grounded-refusal
  -> Agent Runtime -> Tool Registry -> Decision Guard -> 确认/恢复/取消
  -> SQLite（本地与测试）或 PostgreSQL + pgvector（集成与生产）
```

PDF、Markdown 和 TXT 的原文件只在请求内存中解析；持久化的是提取文本与来源定位，不是原文件。资料文本按不可信输入处理，不能覆盖系统规则或触发工具。

- 检索固定集包含 10 份资料、50 条中文查询，分别运行 keyword、dense、hybrid；hybrid Recall@5 为 `0.94`，keyword/dense 为 `0.94/0.28`。
- 问答固定集为 32 条，覆盖可回答、跨资料、资料不足和冲突资料；资料不足 F1 为 `0.8571`。初始 `0.4` 与失败样例均保留。
- 上述均来自固定离线 Mock embedding 集，不能写为生产真实 embedding 指标。
- 冲突资料仅验证引用范围；未实现冲突检测、来源权重或自动裁决。

## Agent 真实模型边界

历史 A0 固定集在授权下执行 20 场景 x 3：60 Run、107 次 Provider 请求、工具选择 `0.6333`、确认完整性 `0.5556`、恢复 `1.0`，保留 22 个失败 Run 和 84 次安全回退。这是原始失败基线，不是稳定能力宣传。

REL corrected 真实 Provider 集同样完成 60 Run，但 fixture 与 A0/A2/A3 不同，且包含 Runtime 确定性决策和本地 `autoConfirm=true` 回滚夹具。其 `1.0` 系统结果只能证明该 corrected 工程契约在固定条件下通过，不能作为历史模型指标提升。

Guard 召回 `1.0` 一律指真实 Provider 返回后注入固定非法 JSON 的拦截测试，只说明 Guard 链路，不衡量模型自然非法输出率。完整请求、Token、成本、失败项和不可比较说明见 [最终验收报告](../evaluation/产品收口最终验收报告.md)。
