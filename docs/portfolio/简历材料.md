# 学习智能助手简历材料

以下内容面向 Agent 应用后端或 AI 应用工程岗位。所有当前数字以 [产品收口最终验收报告](../evaluation/产品收口最终验收报告.md) 为准；离线 Mock、真实 Provider、浏览器回归与固定角色夹具必须分开表述。

## 推荐 4 条版本

适合项目经历保留 5-7 行空间时使用。

- 设计并实现 FastAPI 可控学习智能体：以持久化 `AgentRun/AgentStep` 驱动 Context -> Decision -> Guard -> Tool -> Observation 多步循环，支持高风险动作确认恢复、拒绝、取消互斥、幂等写入和 rule-based 安全回退。
- 实现 PDF/Markdown/TXT 内存式摄取与 PostgreSQL/pgvector 混合检索，保留页码/标题定位；使用 `halfvec(2048)` HNSW 候选召回、原始 `vector(2048)` cosine 重排和 RRF 融合，在 10 份资料、50 条中文查询的固定离线 Mock 集上取得 hybrid Recall@5=`0.94`。
- 打通“目标 -> 资料 -> 引用问答 -> 错题/薄弱点 -> 草稿确认 -> FSRS -> Today”闭环；黄金流程 E2E 与三种固定角色夹具验证确认前零正式写入、确认后复习调度和 Today 状态变化。
- 建立 Mock、PostgreSQL/pgvector、Playwright、Ruff 与敏感扫描的分层门禁：当前为 `200 passed, 6 skipped`、`6 passed, 200 deselected`、`10 passed`；保留真实模型 Token、成本和失败样例，区分 Runtime 正确性与模型决策质量。

## 精简 3 条版本

适合一页简历或需要为实习经历留出更多空间时使用。

- 基于 FastAPI、PostgreSQL 和原生 JavaScript 构建可恢复多步学习智能体，持久化每个决策与工具 Step，并实现 Decision Guard、工具风险分层、确认恢复、取消互斥和幂等写入。
- 实现 PDF/Markdown/TXT 安全摄取和 pgvector RAG，通过 halfvec HNSW 候选召回、2048 维全精度重排与 RRF 融合，在固定离线 Mock 集上取得 hybrid Recall@5=`0.94`、资料不足 F1=`0.8571`。
- 建立分层自动化与黄金流程验收：全量 Mock pytest `200 passed, 6 skipped`、PostgreSQL/pgvector `6 passed, 200 deselected`、完整 Playwright `10 passed`；真实 Provider 评测保留失败证据，不将 Mock 成绩宣传为模型能力。

## 面试披露边界

- `hybrid Recall@5=0.94` 来自固定离线 Mock embedding 集，不是真实 embedding 生产指标。
- 历史真实 DeepSeek 固定集为 60 Run、107 请求，工具选择 `0.6333`、确认完整性 `0.5556`、恢复成功率 `1.0`；它有 22 个失败 Run，不可宣传为稳定模型能力。
- REL corrected 真实 Provider 集的 `1.0` 结果与历史 fixture 不同，且含 Runtime 确定性决策和本地回滚夹具；不将其接入 A0/A2/A3 曲线或写成纯模型提升。
- Guard 召回 `1.0` 来自真实响应后的受控非法输出注入，只证明拦截链路。
- 公开 Demo 和 91 秒录屏使用 Mock Provider；固定角色验收不是用户研究。
- 早期目标、任务和进度看板属于协作开发；2026-07-06 后的 Agent Runtime、Guard、工具、确认恢复和第七版工程化能力为个人独立实现。
