# 第七版简历材料

以下内容面向 Agent 应用后端或 AI 应用工程岗位，只使用截至 2026-07-20 已提交的代码、固定数据集和自动化证据。

## 推荐 4 条版本

适合项目经历保留 5-7 行空间时使用。

- 设计并实现 FastAPI 可控学习 Agent：以持久化 `AgentRun/AgentStep` 驱动 Context -> Decision -> Guard -> Tool -> Observation 多步循环，支持高风险动作确认恢复、拒绝、取消互斥、幂等写入和 rule-based 安全回退。
- 实现 PDF/Markdown/TXT 内存式摄取与 PostgreSQL/pgvector 混合检索，保留页码/标题定位；使用 `halfvec(2048)` HNSW 召回 Top 100、原始 `vector(2048)` cosine 重排和 RRF 融合，在 10 份资料、50 条中文查询的固定离线 Mock 集上取得 hybrid Recall@5=`0.94`。
- 建立数据库会话、Origin 校验、PostgreSQL 原子限流与模型额度、敏感字段脱敏和 grounded-refusal；通过 `150 passed` Mock 回归、`4 passed` PostgreSQL/pgvector 集成测试及桌面/390px Playwright 验证核心链路。
- 搭建固定评测与真实模型成本护栏：覆盖 32 条四类问答和 20 个 Agent 场景，资料不足 F1=`0.8571`；完成 DeepSeek 20 x 3 真实运行，记录 107 次请求、Token、成本及逐 Run 失败证据，用于区分 Runtime 稳定性与模型决策质量。

## 精简 3 条版本

适合一页简历或需要为实习经历留出更多空间时使用。

- 基于 FastAPI、PostgreSQL 和原生 JavaScript 构建可恢复多步学习 Agent，持久化每个决策与工具 Step，并实现 Decision Guard、工具风险分层、确认恢复、取消互斥和幂等写入。
- 实现 PDF/Markdown/TXT 安全摄取和 pgvector RAG，通过 halfvec HNSW 候选召回、2048 维全精度重排与 RRF 融合，在固定离线 Mock 集上取得 hybrid Recall@5=`0.94`、资料不足 F1=`0.8571`。
- 建立 Mock/真实模型分层评测、PostgreSQL 集成测试、Playwright 和敏感信息扫描；完成 DeepSeek 60 个固定 Agent Run，并保留 Token、成本及失败样例作为后续优化基线。

## 面试披露边界

- `hybrid Recall@5=0.94` 来自固定离线 Mock embedding 集，不是真实 embedding 生产指标。
- 真实 DeepSeek Agent 为 60 Run、107 请求，工具选择 `0.6333`、确认完整性 `0.5556`、恢复成功率 `1.0`；主 Bullet 强调评测体系，不把弱指标写成模型能力成功。
- Guard 召回 `1.0` 来自真实响应后的受控非法输出注入，只证明拦截链路。
- 公开 Demo 和 91 秒录屏使用 Mock Provider。
- 早期目标、任务和进度看板属于协作开发；2026-07-06 后的 Agent Runtime、Guard、工具、确认恢复和第七版工程化能力为个人独立实现。
