# AI-Agent

通用成长学习助手 App 的第一版可运行原型。

## 当前版本

- 创建成长目标
- 添加学习或成长资料
- 自动整理资料摘要和知识点
- 自动生成 7 天行动计划
- 生成闪卡和简单测试题
- 支持成长问答
- 支持任务打卡和进度查看
- 数据保存在浏览器本地

## 使用方式

直接打开：

```text
app/index.html
```

或使用本地预览服务访问页面。
