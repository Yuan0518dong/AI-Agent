# 学生助手 App 开发

这是学生学习智能体 App 的第一版可运行原型。

## 当前版本

- 创建学习目标
- 添加学习资料
- 自动整理资料摘要和知识点
- 自动生成 7 天学习计划
- 生成闪卡和简单测试题
- 支持学习问答
- 支持任务打卡和进度查看
- 数据保存在浏览器本地

## 使用方式

直接打开：

```text
app/index.html
```

## 版本控制

本项目使用 Git 管理。第一版提交用于保存 PRD 和可运行原型。
